# R43：Q版三视图一致性与真实桌宠交互（内置角色直接可用）

这是对**已经在安装包中的角色**增加的功能，不需要用户下载安装素材，也不会重新发布作者图片。

## 用户可见的变化

进入 **系统 → 角色管理 → Q版三视图·交互**，选择已安装的任意真实角色（包括私有完整包已有的作者素材角色）。打开的窗口包括：

1. **正面、侧面、背面原画对照**：共用相同缩放比例、底部着地线位置，不能因每个角度图框不同而拉长角色身体或改变头身比。
2. **真实 PNG 动画交互**：点击“正面待机”、“向左移动”、“向右移动”、“摸头反馈”、“拖拽反馈”、“休息 / 落地”、“下落”后，逐帧播放该角色 `pet_conf.json` 与 `act_conf.json` 真正绑定的图片；缺失动作按钮禁用，绝不生成假动作。
3. **不伪造背视图**：现有原神角色的 `up/down` 常复用正面动作，不能视为独立背面。没有真正同源正交背面素材就明确写“缺少独立背面原画”，不镜像正面，不拿不同作者版本拼接。
4. **私有原画无修改**：图片仍从现有角色目录读取，预览不上传原画、也不在角色目录生成新的版权受限素材。

## 使用真实同一版本三视图

已有三视图的角色可在其目录内保存 `Q_CHIBI_3VIEW.json`，登记原画的固定 URL、同一画师、造型版本和**三张不同 PNG** 的 SHA-256。例如：

```json
{
  "schema_version": 1,
  "source_url": "https://example.org/artist/source-model",
  "artist": "同一画师署名",
  "variant": "确定的一套服装与造型版本",
  "views": {
    "front": {"file": "threeview/front.png", "sha256": "64位SHA256"},
    "side":  {"file": "threeview/side.png",  "sha256": "64位SHA256"},
    "back":  {"file": "threeview/back.png",  "sha256": "64位SHA256"}
  }
}
```

三个图也可以指向原生 `action/帧名.png`；源码拒绝跳出角色目录的路径、软链接、过大/变更后的 PNG、重复三视图，避免把同一帧镜像称作背面。结构和哈希校验只证明这是登记的原画素材，**不能证明它确实符合角色原设**，仍须人工对照五官、配饰、服装、背面轮廓、头身比和侧面转身连续性。严禁将版权受限原作模型直接复制到公开源码仓库。

## 交互验收重点

- **左右移动**：侧身造型与正面头发、帽子、衣装及道具必须是同一个角色版本。左右动作各有真实关键帧；需要区分真正脚步变化和整图平移。
- **摸头**：点击交互预览应播放原始 `patpat` 绑定，而不是总切回待机。
- **拖拽 / 下落 / 休息**：检查落地线稳定、爪脚方向和身高比例，不因不同动作 PNG 的边界大小产生显示变形。
- **背面**：绝不将 `up` 或 `right` 直接当背视。缺图保持待补，同源三视图须另行完成。

### 真实工作范围

R43 新增的是**统一比例与真实互动的比较播放器 / 三视图来源对齐机制**，不擅自改写有许可限制的角色美术。对于现有角色尚未取得独立背面素材的情况，仍然没有“三视图完成”的结论；项目中角色数量不会因本轮测试虚增。R43 不解除 R42 私有直接内置包因 GitHub Windows Runner 未分配而未成功生成新版本的问题。
