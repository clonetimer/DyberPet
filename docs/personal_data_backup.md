# DyberPet 完整存档与设置备份（P0 用户功能）

## 使用方法

进入 **系统 → 存档管理 → 备份完整存档与设置（ZIP）**，选择一个尚未存在的 ZIP 路径。软件会将当前设置、养成数据、待办及动作数据落盘，再从 **真正的用户配置目录** 生成带 SHA-256 清单的备份。备份完成时会再次校验 ZIP。

需要检查过去创建的备份，选择 **校验完整数据备份**。该操作仅查看文件，不会修改现有存档。

## 包含与不包含

包含：`data/settings.json`、`data/pet_data.json`，以及存在时的 `task_data.json`、`act_data.json`、`version`。

不包含：用户另行安装的角色图集、语音资源、模型文件、其他目录或第三方游戏素材。如果要迁移整套个性化角色，也需要另行备份经用户授权使用的角色素材目录。

Windows 便携版数据通常在程序所在目录 `data/`。Linux 数据一般位于 `~/.config/DyberPet/data/`。本次同时修正旧版“导出存档”和“快速存档”在 Linux 误读取程序资源目录的问题。

## 恢复边界

已有 **导入存档** 功能只恢复角色养成相关数据；**不能把完整 ZIP 直接导入运行中的 DyberPet 来覆盖设置**。完整 ZIP 的自动恢复、跨设备迁移和回滚将在独立阶段实现，届时需要进程停止校验以及损坏时回滚机制。在此之前，请将 ZIP 妥善保管，必要时关闭程序，由用户对照 ZIP 中的 `data/` 手动处理，先备份本机现有目录。

## 安全与验收

- 不覆盖已有的同名 ZIP，失败时清理临时文件。
- 拒绝未知归档成员、路径穿越、符号链接、大小超限、重复项和 SHA-256 不一致。
- 不上传备份到云端、不下载图片或音频。
- Windows/Linux 的 CI 使用临时目录生成并验证备份；并不代表完成真机长期运行或完整恢复验收。
