# DyberPet 完整存档与设置备份（P0 用户功能）

## 使用方法

进入 **系统 → 存档管理 → 备份完整存档与设置（ZIP）**，选择一个尚未存在的 ZIP 路径。软件会将当前设置、养成数据、待办及动作数据落盘，再从 **真正的用户配置目录** 生成带 SHA-256 清单的备份。备份完成时会再次校验 ZIP。

需要检查过去创建的备份，选择 **校验完整数据备份**。该操作仅查看文件，不会修改现有存档。

## 包含与不包含

包含：`data/settings.json`、`data/pet_data.json`，以及存在时的 `task_data.json`、`act_data.json`、`version`。

不包含：用户另行安装的角色图集、语音资源、模型文件、其他目录或第三方游戏素材。如果要迁移整套个性化角色，也需要另行备份经用户授权使用的角色素材目录。

Windows 便携版数据通常在程序所在目录 `data/`。Linux 数据一般位于 `~/.config/DyberPet/data/`。本次同时修正旧版“导出存档”和“快速存档”在 Linux 误读取程序资源目录的问题。

## 完整 ZIP 恢复（独立向导）

进入 **系统 → 存档管理 → 恢复完整存档（需退出桌宠）**。确认后，桌宠会保存当前状态、启动独立恢复向导，然后退出。恢复向导中：

1. 点击「选择并校验 ZIP」，读取以前创建的完整数据备份；若 SHA-256、文件清单或格式异常，将拒绝恢复。
2. 确保原桌宠已经退出，再点击「确认恢复」，独立向导必须获取与桌宠相同的单实例锁。获取不到锁时**不修改任何数据**，请从系统托盘彻底退出程序后重试。
3. 在恢复前，程序会自动生成独立的原数据 ZIP（SHA-256 验证），同时将整个旧 `data/` 目录保留为 `.dyberpet-pre-restore-…`；新数据在相邻临时目录中准备并校验完成后才切换。成功后**重新启动桌宠**即可使用恢复数据。

Windows 便携版可以从已解压的可执行文件入口打开该恢复向导；Linux 同样支持。原始角色图像、个人语音、外部 AI 模型**不会**随完整 ZIP 恢复；迁移到新电脑时要另外管理用户有权使用的个人资源。

如果恢复中途操作系统崩溃，在下一次启动时会检查**受限格式的恢复事务日志**：若活动 `data/` 不存在，但保留的旧数据仍在，则只还原旧目录；**绝不覆盖已存在的活动 data 目录**。无法安全判定时阻止自动操作，需人工核查。

原有「导入存档」仍只恢复角色养成数据，不等于完整恢复；两者独立。

## 安全与验收

- 不覆盖已有的同名 ZIP，失败时清理临时文件。
- 拒绝未知归档成员、路径穿越、符号链接、大小超限、重复项和 SHA-256 不一致。
- 不上传备份到云端、不下载图片或音频。
- Windows/Linux 的 CI 使用临时目录生成并验证备份；并不代表完成真机长期运行或完整恢复验收。
