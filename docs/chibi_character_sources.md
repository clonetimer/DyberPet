# Q版角色素材入口与实际接入

这里记录可以定位到的实际素材入口。Q版模板只有动作映射、显示与气泡参数，不包含作品方授权或角色美术图片。

| 角色 | 素材入口 | 接入方式 | 权利说明 |
|---|---|---|---|
| 派蒙（原神） | [Codex Pets：Paimon](https://codex-pet.org/zh/pets/paimon/)；[本项目原有迷你宠物合集](collection.md) | Codex 图集可转换为主桌宠；原生迷你宠物包不能当作主角色导入 | 请分清主角色与迷你宠物两种类别；公开下载不等于可再分发 |
| 纳西妲（原神） | [本项目已有角色合集](collection.md)中的纳西妲 | 原生 DyberPet MOD | 已有角色包，直接走原有导入机制，不得擅自二次发布 |
| 阿丽莎（无限机兵） | 用户自行绘制、委托或取得许可的透明帧 | GIF/APNG/PNG | 暂未证实具有再分发许可的完整 Q版动作包 |
| 咕嘎、Doro | [Codex 图集导入说明](codex_character_import.md) | V1/V2 图集 | 核实画师与对应具体素材授权 |

## 已有 DyberPet 原生角色（纳西妲）

从 [原有角色合集](collection.md) 下载纳西妲主角色模组。若素材已经解压，进入 **系统 → 角色管理 → 添加角色 → 选择角色文件夹**，选择包含 pet_conf.json、act_conf.json 和 action 目录的角色文件夹，使用原有导入逻辑。

如果下载的是单个 **原生 DyberPet ZIP 包**，可以选择 **系统 → 角色管理 → 添加角色 → 选择原生角色 ZIP 压缩包**，无需手动解压。导入器检查压缩包路径安全、帧资源、动作引用、脚本文件和重名冲突；同名角色自动使用新目录，不影响已有角色。不是所有 ZIP 都是主角色包，迷你宠物 ZIP 会给出明确拒绝提示。

## 派蒙：主角色与迷你宠物要区分

[DyberPet 原有合集](collection.md)将派蒙列在**迷你宠物**而非主角色清单中。原生迷你宠物使用 res/pet 结构，与主桌宠 res/role 是不同加载链路，因此不能把其 ZIP 直接安装为主角色。

若要派蒙成为可以切换的**主桌宠**，把 Codex Pets 的 pet.json 与 spritesheet.webp 放在一个文件夹，打开 **添加角色 → 选择角色文件夹**，选择「原神 · 派蒙」Q版模板。导入器生成主角色，保留悬浮动作。

若只想要**伴随主角色运行的派蒙迷你宠物**，应使用 DyberPet 自带的迷你宠物管理功能及其原生资源包。两种形式可以共存，但不可直接互换。

## 自制 GIF/PNG 动画（阿丽莎及其他角色）

文件夹约定：

    MyChibiArt/
        idle.gif          # 必须
        left_walk.gif     # 可选
        right_walk.gif
        wave.gif
        jump.gif
        wait.gif
        sleep.gif
        review.gif

也可使用 idle_0.png、idle_1.png、wave_0.png 等编号帧，或单帧 idle.png。支持 GIF、APNG 与静态 WebP。所有动画最好为透明背景。图集可以缺少非必需动作；未提供的动作使用待机回退。

选择 **添加角色 → 选择角色文件夹**，再选择「无限机兵 · 阿丽莎」或其他 Q版模板即可。转换在工作线程执行，不阻塞现有角色文件。

## 导入后核对

角色目录中将生成：

- ANIMATION_PREVIEW.png：各动作前 8 帧的拼图，方便人工检查错帧、透明度、站立动作漂移
- IMPORT_REPORT.json：各动作帧数、脚底基线、画布裁切情况、近似时长与警告
- info/pfp.png、info/cover.png：生成的头像和信息卡封面
- ASSET_SOURCE.txt：素材源与许可说明

静态图片只能生成静态角色，不能声称拥有未提供的走路、跳跃或睡眠动画。自动测试不等同于 Windows 实机运行验收。
