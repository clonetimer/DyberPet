# DyberPet 真实角色形象人工目视审核（2026-10-25）

**验收依据不是源码中存在名字、能下载、测试通过或哈希正确**，而是对当前 `main` 固定提交的实际 WebP/PNG **解码后看图**。使用脚本 `tools/visual_inspection_contact_sheets.py` 从当前安装器所锁定的来源版本提取原始待机/代表帧。未对原图绘制、重新设计、平滑修饰或伪造形象。本报告为**静态代表帧视觉初审**，不声称对每一帧、所有动作、声音或 Windows 实机完成验收。

## 重要范围

当前 main 自带的可玩 `res/role/` 仅 **Kitty、ChrisKitty**，以及非独立可玩角色的 `sys` 特效目录。其他 **17 项来源选项（12 套 Codex 原神、3 套原神原生动画、咕嘎、Doro）都是安装器在用户选择后下载**，不是默认内置 17 套图片。用户历史目录若仍残留 125 套低保真旧生成角色，新的打包清理不自动删除这些个人目录。

- `doro--godxxy1229` (V2)：粉发、紫眼、玫瑰发髻、白色四足横向身体；**最接近公开流传的 Doro 经典梗图轮廓**，推荐作为原设优先选项。原画文件长度 702,066 字节，Git blob `c8aeb0bfe877371f25d660b3d95a9e7e58191daf`。

## 整改与门禁

1. **P0：Doro 默认来源不得继续标记为形象验收通过。** 改用四足原设轮廓版本（godxxy1229 优先），可提供 vaevie 细节版备选；旧版的既有本机安装需明确“旧直立版”和独立重装，不在后台覆盖个人素材。
2. **P1：咕嘎蓝金异瞳在作者实际图上再核对**，不宜把“源文件一致”写成与经典梗图 100% 高保真。
3. **P1：首启必须正确告知用户**：Kitty/ChrisKitty 是极简像素基础角色，其他高辨识度角色需要在安装向导选择下载；“17 个来源选项”绝非“出厂带有 17 个高保真角色”。
4. **P1：真实画面验收**：每套至少目视待机、左右行走、互动、拖动四组代表帧，再进行 Windows 100%/150%/200% DPI 与不同缩放下的肉眼核对。
