# DyberPet R6：同人物真实原画 A/B 动画同步对照

## 为什么做

已有 R5 65 个独立角色、67 套作者素材，其中绫华和温迪各有一个透明画布稳定化备用版本。对于反馈“原设Q版应该圆润，当前部分角色却像细长立牌”的问题，R5 的单卡片浏览要求不停切换页面，难以判断同一角色哪套原创者图像体态更好。

## R6 用户流程

1. 角色库打开「真实Q版原画对照墙」。对于**同一身份**有两套以上已安装作者 PNG 的人物，点击「同人物 A/B 对照」。只有一个来源时，该按钮禁用。
2. 左右各指定一个**不同且身份相同**的作者素材版本。不能把两个不同原神人物、咕嘎和 Doro、或抽象演示角色拼成“同一人物”。
3. 左右展示当前版本**各自原生 PNG**。选择「只裁透明边缘」可更直接比较头身宽高；选择「保留原始画布」则观察真实尺寸、定位与脚底锚点。两种选择都只裁剪显示，不修改任何作者 PNG 文件。
4. 点击「同步播放」，两侧按照同一时钟步进，但分别循环自己原动作的帧数。**不会混合两套动画、不复制帧、不做人物像素拉伸**。对于同类真实互动动作，可使用「两侧同步切到该动作」；支持已存在的散步、奔跑、攀爬等，以及两侧确有的拖拽、下落、落地动作。
5. 任意一侧可「逐帧核对并保存此版本Q版/立牌意见」。审核保存仍遵循 R4 完整人审 + 全图帧审计：原设辨识、圆润Q版体态、动画、桌面实际播放都必须人工通过；R6 的 A/B 同屏**不是**官方原画相似度证书。
6. 对绫华、温迪的原版本与 R5 的 `SourceCanvasR5Ayaka` / `SourceCanvasR5Venti` 候选特别对照，判断是否减轻高瘦立牌感觉、动画是否自然。没有必要切换桌宠当前活动人物。

## 保障

- 全部图片来自本机的 `res/role` 作者素材，不另行下载、生成、替换或上传。
- 按导入收据验证身份；角色目录不能有路径遍历和符号链接，不接受标记为演示图的素材。
- 两侧只使用当前版本真实存在、逐帧可解码的原生动作；双方没有共有互动时不能假造。同步预览的统一节奏不等于作者原始桌面实际帧率。
- Windows 便携式 EXE 显式收集 A/B 对照窗口；Windows/Linux Qt 回归核验不同帧数循环、来源未被修改、跨身份隔离、透明预览裁边不会改变磁盘原图。
- R6 不增加已安装独立人物数（保持 65），也不把 67 套作者来源算作 Q版认证通过。
- 真实 Windows 用户视觉品鉴、原设声线、长期运行互动、第三方图像再分发许可仍需独立验收；发布仍为个人候选版而不是 Stable。
