# R44：Q版角色轮廓等比例修正与实际动作质量提示

**目标**：直接改善已经内置到软件中的真实作者角色预览，不再要求使用者下载、导入或手工安装角色。

## 修复的具体问题

R43 以原始 PNG **画布尺寸**对齐角色。但是不同原作者的动作有可能存在不同程度的透明留白（如正面图 128×128，侧面图 256×256，但两个真正可见的角色都是 40×80）。直接按画布等比放置，会让同一个角色在侧面突然缩小一半，也可能因脚底下方留白变化造成落地位置不一致。

R44 使用每个作者原图的 **alpha 可见轮廓**计算宽高、底线和中心点，所有正面/侧面候选及各个交互动作使用**统一的可见轮廓缩放尺度**。图片仍是原生未改动的 PNG，Qt 仅改变显示位置。动作采用**整段动作（最多等距采样 24 帧）的轮廓合并边界**作为稳定锚点，而不是每一帧重新“贴地”；这样“跳跃”本身真实的上下运动仍然保留，不会被错误消除。

## 角色观感与交互问题提示

实际源帧检测会向「Q版三视图·交互」窗口显示：

- 左右走路有多帧，但实际画面没有姿态变化；
- 左右移动调用了同一原生动作或相同原始帧；
- 动作序列含全透明图片；
- 有可见角色部位触及 PNG 画布边缘，可能发生裁切；
- 原作者 PNG 可能含未抠除的不透明背景；
- 正、侧两张可见角色身高差异较大，需检查是否跨人物版本；
- 尚未取得同一作者、同一造型真实背面原画。

这些都是 **复核线索**，不是自动判定某位角色的画工优劣、版权许可、头身比合理性或三视图已经通过人工审核。只使用当前安装包内的真实原画，完全不生成镜像背面、不替换原创动作。

## 验收方式

最新源码运行 DyberPet 后，进入 **系统 → 角色管理 → Q版三视图·交互**，选择已经内置的角色，直接比较正面、侧面、背面（若有）和点击左右移动、摸头、拖拽、休息、下落。

跨平台自动测试使用合成的测试夹具检查：

1. 不同透明画布中的同尺寸可见形象被绘制为相同比例；
2. 多帧跳跃的上下移动不会被错误抹平；
3. 原作者图像在预览前后 SHA256 完全相同；
4. 静态假动作、空白帧及左右同源被标记；
5. Qt 真实窗口能打开、播放和暂停原生交互，并保留原生源码加载兼容性。

## 仍未完成的美术任务

R44 **没有新造正、侧、背原画，也没有审美合格数量增加**。完整的美术修正仍要取得或制作每个角色同一造型的真正背面和转身动作，确认素材使用条件，逐项通过人工角色身份、头身比例、服装配色与动作连续性检查。

R42 新版含 69 个创作者素材角色的内置私有完整包此前在 Windows Runner 分配前失败，因此 R44 源码的跨平台 CI 通过**不能等于已经交付更新后的完整角色安装包**；这两项分别验收。
