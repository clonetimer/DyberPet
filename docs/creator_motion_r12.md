# R12：优先复核真正具有不同运动姿态的作者版本

本轮不是生成新头像或插值新帧，而是把原有 R7 的完整 PNG 动作差异分析用于本机 **同人物 A/B 原画对照**。

## 使用方式

打开角色库，进入两个已安装、来源身份相同的人物的“原画 A/B 对照”，选择双方都实际包含的动作（走路、爬行、跌落、拖拽等）。如果一侧动作有 `single_frame_motion`、`translation_only_or_static_pose` 或 `long_identical_pose_run` 风险，而另一侧至少有两帧、两种确实不同的可见姿态且**没有现有运动风险项**，界面会明确指出哪套**更值得人工核对**，展示作者素材文件夹。点击“逐帧核查姿态更丰富的版本”，自动打开该作者版本的**同一原生动作**逐帧窗口。

双方都良好、双方都有明显风险、姿态统计缺失、不是运动动作、或未能证明姿态确实不同，界面保持“暂无足够证据”。绝不会仅凭帧数多就认定更优。点击推荐只查看原作者 PNG，不会切换当前桌宠、覆盖本机存档、拼接其他作者素材或合成动作。

## 同时修复的视觉缺陷

之前已安装 123 角色档案中，除 R8 直接查看样本以外的大多数角色**没有固定原画样本 URL**。原有逐帧预览将 `None` 当作字符串拼接，在捕获异常后把特征核对提示错误地重置为通用文字。R12 对没有原画样本链接的角色显示“人物档案待核对项目”，不再丢失发色、服装、头饰和动作重点，同时明确**未独立查看过该版本 PNG**。

## 验收界限

本次的“更值得人工查看”只对特定动作的非透明像素姿态多样性有判断力，**无法证明**角色对原设的相似度、动作语义是否正确、动作自然性、语音、艺术授权或实机体验。上一轮 R7 发现的 14 套/28 个单帧动作问题并不因此自动修复；仍须找到同一人物可信的真实替代版本并经过人工核对。

固定原画来源仍是 65/123 原神人物；58 人缺来源。R11 双 Windows 构建来自 `150de42`，R12 仅在通过 Linux/Windows 原画 Qt 回归与真实二进制构建后才可认为软件改动已交付。
