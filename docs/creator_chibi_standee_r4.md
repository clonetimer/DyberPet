# DyberPet R4：Q版形象与立牌型角色质量门禁

## 当前真实口径

R3 在个人版中已装入 63 个原神角色的作者来源素材，加上咕嘎、Doro 两套素材，共 65 个。**这仍不意味着有 65 个符合 Q 版形象标准的桌宠**。来源哈希和原生 PNG 结构检查只能证明可导入，不能证明立体感、相似度、动作自然性、原声或再分发许可。

## R4 用户路径

打开“角色库”，可以在“全部候选”“本机Q版合格标准集”“立牌/形象不合格”“已装素材待审核”间切换。默认全部候选显示各自审核状态，而不是把来源已安装误认为完成。一个人物存在多个素材版本时，已通过本机审核的 Q 版会优先打开；被人工判定为立牌/形象不符的版本仍保留作候选对照，不会覆盖作者的原始 PNG。

在“预览本机原画逐帧动作”中新增 Q 版体态选择：未评价、圆润Q版、立牌/细长立绘、其他不合格。用户需逐版本勾选亲自对照原设、已经检查动作、已经在真实桌面播放，并查看每一动作帧。点击“保存本机 Q版/立牌审核”后将评审 JSON 放入软件 data/creator_quality_reviews 目录，不会改写作者素材或上传到 GitHub。

**本机 Q 版合格名单**需同时满足用户圆润Q版判断、A 原设较吻合、已经核对原设、完整逐帧查看、动作人工检查、桌面实测和完整 PNG 运动结构检查。缺少其中任一条件就仍是候选。若 PNG 内容或配置文件修改，旧审核立即失效。这个名单是用户本人的审阅结果，不是官方角色美术或版权认证。

## 全角色风险筛查

角色库支持“导出立牌轮廓与动作风险清单”，只读量取原始 PNG 非透明轮廓宽高比和动作首两帧的实际差异。非常高瘦的轮廓、单帧运动、首两帧完全相同会列为优先人工复核线索。

**自动筛查不会直接宣告哪一个角色是立牌或 Q 版合格。** 长高窄轮廓可能来自正常动作，圆形轮廓也不能说明符合原设。形象与动作质量需人工核对，不复制静止图片凑帧，不用简笔画代替原设。

## 质量统计独立列示

以后分别报告已导入作者素材数量、本机 Q 版合格数量、人工判定立牌/外观不合格数量、动作结构存在问题的版本数、尚未审核数量。未进行人工逐个核验之前，本机合格数量不能擅自写成 42、63 或 65。

R4 尚不改变 R3 个人版素材本身。Python / Rust 预装包需在代码回归通过后单独构建；第三方素材仍不在公开 Release 直接发布。
