# R46：真实鼠标摸头与拖拽的意图区分

本轮直接修复 **DyberPet 主窗口的实际鼠标交互**，不是预览或素材管理功能。继续遵守用户的“已有角色随软件内置，不再逐个下载和本地导入”的要求。

## 已修复行为

旧版代码在 `mouseMoveEvent()` 中，只要鼠标左键按住、哪怕只有 1px 抖动，就会把鼠标动作当成桌宠拖拽：角色窗口开始移动、切换拖拽动作、触发落地/掉落状态。特别是在悬空时，左键**按下瞬间**就被判断为开始拖拽，容易让摸头、点击造成误操作。

新版按 Windows/Linux 桌面原有的 `QApplication.startDragDistance()` 读取系统拖拽距离，限制到合理安全范围 6～24 像素：
- **轻点/鼠标抖动**：既不移动桌宠、不触发 `mousedrag` 动作，也不改变悬空/落地状态。落地角色松开鼠标时触发已有真正原画 `patpat`。
- **真实按住并移动超过阈值**：第一次越过阈值才激活桌宠原生拖拽动作（真实源帧），暂停当前日常动画，并按原本轨迹移动窗口。后续鼠标移动不重复调用起始信号。
- **放手**：沿用原来跨屏幕、下落或关闭重力后的动画恢复流程；点击与拖拽状态都在释放时清零，避免下一次点击被错误继承。

这是输入/交互逻辑修复，不修改角色原始 PNG，不会假造角色动作或追加通用 Q版简笔画。

## 回归与交付门禁

新增 `tools/pet_pointer_gestures.py` 的纯函数，验证单像素误差、恰好到达阈值、系统无效阈值以及异常指针位置。真实 Qt 测试直接调用 `PetWidget.mouseMoveEvent` / `mouseReleaseEvent`：验证抖动不会暂停动画、不会移动桌宠、释放后会进入 `patpat`；越过阈值时恰好触发一次原有原生拖拽交互。Windows/Linux PyInstaller 显式包含新增模块。

## 角色形象的实际剩余

本轮没有修改美术本身：R43/R44 的等比例三视图对照、R45 的原作者专属动作已在 main，但尚未取得所有角色同一造型的独立背面；美术对齐仍需真实原画、相应权利依据及逐角色验收。

**R46 源码验证成功不能等价于私有全原画安装包已交付。** 私有 R7 65 个角色完整 ZIP 目前仍是旧代码，R42 自动重打包的 GitHub 任务在 Windows Runner 分配前失败。后续完整包需要让新代码和有来源的原画在同一私有构建过程中打包，不要求使用者逐角色安装。
