# R45：原画专属互动直接在桌面宠物上播放

本轮针对用户明确提出的“完善角色形象和交互、角色直接内置、不再要求本地安装”。

## 实际新增功能

此前原生 DyberPet 会加载作者角色包中 `act_conf.json` 的全部原始动作（`pet_conf.act_dict`），但普通右键菜单只显示 `random_act` 分组或用户后来配置过的动作。很多已有的原作者手绘动作帧实际上已经在安装包内，却没有独立的直接触发入口。

R45 在**桌宠本体**的右键「选择动作」下增加「**原画专属动作…**」：只显示这个角色已经成功载入、尚未在普通菜单出现的独立作者原生动作，例如原画包已有的 `wavehand`、`sit`、`look`、`qskill` 等（按每位作者实际提供的动作决定，不承诺所有角色都有相同动作）。可选项列出实际帧数、重复次数、预计播放时长；选择后直接在桌面宠物播放，结束后自动回到日常动画。

- 图片：全部使用该角色已经载入的真实 `Act.images`，不下载、不重新生成、不动原始 PNG。
- 动作：在原有 `Interaction_worker` 上新增 `native_action` 处理，保留原始帧间隔、位移方向与动态锚点。
- 时间：按原生动作实际刷新间隔走帧。例如 120 ms 原画帧在 20 ms 定时器下只在六次计时触发后换一帧，桌宠移动也只在真正切帧时推进一次，避免移动速度被意外放大六倍。
- 安全：拒绝不属于当前角色或图片缺失的名字；单次动作时长不超过 45 秒；拒绝异常帧率、空动作、无穷重复。拖拽中不能重新触发此菜单播放。
- 交互结束：播放器结束后通过既有 `sig_act_finished` 信号恢复自主桌宠动画，不把角色锁死在某个动作状态。

## 与 Q版三视图的一致性

R43/R44 已实现正/侧/背的源帧分离、统一可见身形、稳定脚底；R45 补上**在真实桌宠上使用作者专属动作**的能力，不能把预览窗口误认成桌面本体已实现了额外交互。R45 未创建任何新美术：仍缺原生背视的角色不能标为完整三视图，也不将 Doro 类简笔替代像素认作获认可的角色原设。

## 验证

代码门禁包含目录去重、拒绝其他菜单复用的核心动作、原生帧时间精度/重复次数和 45 秒上限、拒绝恶意动作名、Qt 真实 `Interaction_worker` 自动结束回调；Windows/Linux 便携构建显式包含新增源代码模块。

## 交付边界

该功能随最新 `clonetimer/DyberPet/main` 的代码进入后续完整版本。旧私有 R7 65 个角色打包仍是旧版程序；私有 R42 69 角色完整包尚未成功重新构建，不以源码 CI 成功代替“新版完整原画安装包已交付”。
