## 语音验收：明确划分三种声音

- **招牌音效**：单独的“咕咕嘎嘎”拟声或叫声，是一个短音频素材；需要确认特定作者/视频音源的使用权限。若来自他人配音、AI 合成或混剪，应分别核实版权。
- **对话合成声线**：用于读出聊天文本的 TTS。现有 pyttsx3 调用系统语音，**不是咕嘎原声**。只有经明确许可、在本地测试过音色的 TTS 才能称为“选定版本风格的声线”，不能默认认定原配。
- **识别用户说话**：Vosk STT，不会改变桌宠声线，也不是咕嘎音源。

## 本轮已实现的本地操作

桌宠助手右键窗口切换到含“咕嘎 / 咕咕嘎嘎 / guga”名称的角色时，出现“登记本地授权 WAV”“试听咕嘎音效”和“核查当前咕嘎形象”。最后一个按钮将读取当前真正安装的角色目录（`res/role/当前角色名称`），提示动作缺口及“真实性尚未核实”。如果实际未安装咕嘎，按钮会明确报缺少角色目录；其他人物隐藏这些入口。

操作流程：从有明确本地使用许可的作品中自行取得 WAV（软件不提供下载）。点击“登记本地授权 WAV”，选文件、填写实际音频作者和具体 HTTPS 来源，然后人工确认已核查个人使用权限。此操作仅将**路径、音频哈希、来源、作者、用户声明**保存到本机的 guga_local_sound.json 中，不复制音频文件，也不上传到 GitHub。下次试听之前校验 SHA-256，源文件发生变化则阻止播放。

格式条件：本地 PCM16 的 WAV、单/双声道、16/22.05/24/32/44.1/48 kHz、0.1–15秒、最大5MiB。Windows 使用 winsound 本地播放；非 Windows 需额外安装 sounddevice。没有配置 WAV 时，“试听”明确失败而不是偷偷调用系统语音。

**这项功能不会对任意文本作声线克隆，也不会从 B站链接抓取音频。** 当前没有自动将短音效当成任意中文句子的 TTS 能力。

## 本地动作/文件完整性审计

用命令行在仓库根目录执行，指向你实际安装的角色目录（示例目录必须实际存在）：

    python tools/audit_guga.py --role "res/role/Guga" --wav "D:\PetAssets\Guga\signature.wav" --report "D:\PetAssets\guga_audit.json"

如果没有可用语音，也可省略 --wav；如果没有角色，则明确报告错误，不伪造通过。输出 JSON 包含原生角色动作识别、PNG IHDR 参数、缺少说话/走路动作的风险以及必要的人工比对项目。无论帧数多少，报告的 authenticity_status 都为 not_verified，只有对**具体来源**的视频截图、动作和授权进行人工验收后，才能在项目验收记录中声明相应版本通过。
