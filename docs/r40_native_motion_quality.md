# R40：真实作者动作帧质量审查（不改图、不虚报完成）

阶段：2026-10-28。继 R39 纳西妲、魈、流浪者一次下载安装后，针对已有**真实作者源帧**开展机械一致性检查，辅助人工判断动画是否符合用户认可的 Q 版桌宠质量。

## 实施范围

- 3 位栎曦_Nuo 原生 DyberPet 角色：原生 `action/*.png`，一次下载批量或单角色安装均自动生成审查记录。
- 12 个固定版本 Codex 创作者图集：在**用户确认的本机安装之后**，经已存在的转换流程输出原生动作帧，也自动生成同格式审查记录。
- 其余角色本机导入后，可对具体目录直接执行只读 `artist_motion_audit.py`；并不假定 123 套都有合格美术。

## 如何检查

```powershell
# 不联网，不写入或改动任何素材
py tools/artist_motion_audit.py --role ".\res\role\SourceGenshinNahida"

# 首次手工生成本机证据文件；已有同名文件会拒绝覆盖
py tools/artist_motion_audit.py --role ".\res\role\MyCreatorRole" --write
```

报告 `ANIMATION_MOTION_QA.json` 记录现有角色真实动作绑定（默认、左右、摸头、拖拽、坠落、休息、专注），每种动作最多采样 9 张**原始 PNG**，包括：

- 帧数 / 实际采样数 / 画面完全不同的样本数量；
- 相邻重复帧、整帧透明、角色靠近图像边缘的样本数量；
- 是否将待机动作绑定到左右移动、是否左右方向复用同一动作；
- 所有异常只作为**人工复核提示**，不自动删除图片、不重写原始帧、不虚构走路动作。

打开软件内 **系统 → 角色管理 → 安装作者原画角色**，通过上述 3 位或现有 12 个 Codex 作者来源安装角色后，程序会显示动作可疑情况（若有），并保留角色各自的审查 JSON 和原 PNG 帧。之前安装的角色不会被静默更改，可以手工只读审计。

## 严格区别

静态差异检查能发现全相同帧，但不能证明动画符合四足步态、摆臂、口型或角色原设；走路某几帧重复也可能是动画的正常停顿，而非错误。9 个采样图姿态各异，不表示动作就连贯或美术精致。

用户已经明确接受了中文创作者 0x4682B4 / MelanTech 的 Doro 审美方向，其他角色也必须分别对照自己的**原设人物**，而非依赖此脚本或画风统一成几何简笔画。真实模型与声音版权、动作播放、界面交互和 Windows 物理实机仍单独验收。

任何未经明确再分发许可的作者模型/图像不进入公开 DyberPet 或私有 ChatGPT-Download 本仓库，这个脚本只记录本机质量摘要。
