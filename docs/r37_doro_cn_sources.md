# R37：Doro（朵拉）中文互联网美术来源重新筛选

> 2026-10-28 复核。用户明确反馈此前推荐的 Sketchfab blatz729 Doro 3D 模型**不符合预期的审美**。因此将其**撤销为第一优先级/不予自动采用**，不再因为“可下载 / 有 3D 几何”就判断美术合格。下述素材均处于**候选审核**；暂不新增高保真完成角色数。

## 选型结论

**第一审美基准**：0x4682B4（六碳糖）的 Dororong 四足 Live2D 形象与 MelanTech 的 `Dororo` 桌宠展示。**第一实机参考**：MelanTech/Dororo；**第二实机参考**：waterfeet/DoroPet_V2。它们并非两套独立原画——后两者的项目介绍都指向 0x4682B4 的模型。

- 造型：粉色分束刘海与玫瑰发髻、紫色大眼、蝴蝶结、极短四足、圆润白色身体、简洁小嘴与鲜明轮廓。
- 动态：眼部跟随、轻微呼吸、走动/四足小跑、被抚摸反馈、拖拽、睡眠/特殊表情；保持 Doro 原有古怪而可爱的体态，不人形化。
- **拒绝**：成人少女体型、写实犬猫体型、粗糙低模立体块、并非同一作者版本的前侧背拼图、静态素材整体平移假步态、来源不清的“自称官方”版本。

## 对 DyberPet 的实施方案

1. **先审美、后几何**：以 0x4682B4 / Dororo 截图核对正面和 3/4 姿态、四足比例、发髻与眼睛。不要根据模型能导出 GLB 就自动签核。
2. **两条生产路径并行调查**：
   - *2D 路径*：在合法获得对应模型及本地制作许可的前提下，以 Live2D/原始动作驱动并导出原生 PNG 动作帧；记录唯一作者来源、模型哈希和动作帧 hash。**需要取得/制作与同一人物一致的侧/背参考**，不能冒充 Live2D 现有动作就是三视图。
   - *3D 路径*：寻找**风格确实接近第一审美基准**的、可合法使用的 3D 模型，用 R35 生成正、侧、背正交视图，使用 R36 lineage 和真实 clip 动作门禁。没有合格模型就暂缓，不拿丑模型填坑。
3. **美术审核卡**：对比用户预期 Doro、同一作者来源正/侧/背以及每组动态关键帧；独立记录轮廓、头身比、配色、发饰、动态、桌面缩放。若不符则拒绝，不因为自动化通过标完成。
4. **许可分仓**：DyberPet 公开仓库只保存来源链接、工具和校验报告；私有 ChatGPT-Download 仅保存**允许该存储行为**的素材；明确禁止再分发的 Live2D 模型不要上传，即使私有也不例外。
5. 完成判据仍为同源三视图/合格视角参考 + 实际动态美术 + Windows 实机验收 + 相应权利允许的交付方式。当前只有来源发现，没有新增完成动作或可安装新包。

## 关于“三视图”的重要边界

Live2D 擅长 2D 形变、表情和有限视角变化，**不能自动提供物理正确的模型背面与正交侧面**。如果只有前面和斜前方，就必须再获得同一画师的补充设定图，或转向经审美确认的合法 3D 同版模型；不得从其他画师的图里拼接“背面”后标记审核通过。
