# 轮流语音对话与原生桌宠反馈

## 目标与接续

接续 `c460a95` / PR #99。原主线为流式对话、记忆人格、双向语音、多步骤任务和性能体验；本批补齐 P2 的日常往返：用户开启一次后，说完一句即可得到模型回复和朗读，再继续说下一句。同步把听/想状态接入现有桌宠引擎，已有说话反馈继续复用。用户要求整批推进，不再增加阶段审批或诊断功能。

## 实施选择

- 实施者选择显式开启的轮流语音会话，复用 Vosk、现有本地流式请求和可中断 TTS，以及单 worker。按“听一句 → 生成 → 朗读 → 再听”串联，麦克风与本机朗读不同时工作。
- 不以自动点击现有听写/发送按钮实现，因为那会覆盖键盘草稿、消费附件，并混淆停止和句末。
- 声学全双工、唤醒词和免按钮打断需要回声消除和硬件评估，不在本批声称完成；本批提供明确的“打断，继续听”按钮。保留成熟桌宠，不替换渲染引擎或重做聊天应用。

## 用户行为

“开始语音对话”旁明确说明：说完一句后自动发送给当前本地模型并朗读，回答完成后继续听；仅本次开启有效，不自动随程序启动或保存为常开偏好。原“连续监听”仍为用户检查文字后手动发送的听写。

控制有“开始语音对话”“打断，继续听”“结束语音对话”。界面分别显示准备监听、实际监听、生成、准备朗读、实际朗读、正在打断/结束及终止原因。按钮打断先取消旧任务，等 worker 结束后再听；结束优先于打断，不再重新打开麦克风。已有各阶段停止按钮结束本场语音会话。

控制组固定在滚动内容外，阅读历史或底部操作时仍可见；此布局要求来自本批实际截图中发现的控制入口离开视口问题。

语音不覆盖键盘草稿，不读取或消费待手动发送的文件附件；复用当前角色已完成历史、批准的记忆和可选 PPL 状态。只有完整成功回合写入角色历史。语音仅进入文本聊天，不生成任务或执行文件操作。语音会话自行管理朗读，不能与普通聊天 auto_speak 重复播报。

## 语音轮次与资源

新增 `VoiceTurnRecognizer(model_dir)`，`listen(stop_event, *, on_partial=None, on_ready=None, sample_rate=16000, max_seconds=30.0) -> str`。首个非空 Vosk 完整语句结束本轮；空分段继续等，停止后返回空串且丢弃尾部识别结果。30 秒边界可取非空最终文本，无有效文字则报告超时并结束本场，不无限重试。

同一会话复用已加载的 Vosk Model，每轮新建 recognizer 和麦克风流；所有加载、识别、流打开/关闭都在 worker。构造对象不导入音频模块、不加载模型。TTS 引擎保持现有每 worker 创建和清理方式。原始音频不保存。单轮最多 2000 字符；会话最多 20 个已完成回复轮次、10 分钟，达到限制后明确结束，可重新开启。

## 编排与身份

新增 `VoiceConversation(QObject)`，弱引用宿主 `PetAssistantDialog`。独立 epoch 与 host `_session_generation`、配置快照共同界定本场；角色、人设、模型地址/ID、识别目录、PPL 地址/开关变化或关闭窗口立即撤销会话与排队后继。

成功回调只保存待运行阶段，下一段必须在宿主 `_job_finished()` 清理旧 job 后，通过单次 Qt 定时事件推进并再次验身份。不使用 100ms 自动朗读作为流程控制。只有当前会话所拥有的任务能推进；重复开始、排队成功、旧 ready/partial/finished、打断与关闭竞态均不得复活已结束会话。

模型/音频错误、空答案、准备失败或无语音超时结束本场并保留可读提示；不后台重试。所有停止是现有协作取消，不能声称强行抢占原生驱动阻塞调用。

## 原生角色反馈

宿主发出 `interaction_changed(character, phase)`，phase 为 `idle/listening/thinking/speaking/stopping`，同角色同状态只在变化时发出。监听与说话只在实际 ready 后进入；准备阶段不冒充设备工作。

PetWidget 通过现有原生动作和气泡响应听/想状态。只选择真实存在、已解锁且验证为无声的适配动作；没有合适素材则使用原气泡或保留原动画。动作不能抢占拖拽、跟随、坠落或正在执行的用户交互，不按部分识别或 token 重播。说话沿既有 speech_started / speech_finished 路径，避免重复动作和气泡；状态结束只解除 AI 状态，不停止用户动作。

## 验证和边界

先做语音轮次和 Qt 两轮往返的失败回归，再实施。受控音频驱动只替代设备边界；实际 QThread、Qt 事件循环、流式 HTTP、角色历史和宿主原生方法保持真实。覆盖停止/打断、空语句、配置变化、排队下一段、草稿/附件保留、无声动作和用户交互优先。

完成一次独立审阅、最低 Python/Qt 与完整套件验证，更新原分支、经验、实际截图和候选包。不将受控音频/回环模型当作真实声卡、模型质量或完整 P2 全双工验收。
