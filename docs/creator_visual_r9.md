# R9 · 全人物形象核对提示与真正逐帧动作 A/B 复核

## 验证身份、检查外观和确认动作是三种不同证据

R9 在 **只读、本机** 的原画预览和同人物 A/B 对照中增加了：

1. **123 位原神角色的外观检查表**：使用项目现有的 `GENSHIN_ROSTER[*].visual_checks` 和 `motion_checks`。这只是角色模板里的发型、帽饰、衣装、特征动作核对提示，**不是直接查看过该角色的原画**，也不是任何官方美术认证。只有具备明确来源角色绑定的本机文件夹才显示对应人物的信息，不再从目录名猜测身份。
2. **已直接看过的三个 PNG 样本保持特殊标识**：纳西妲、魈、流浪者有 R8 固定来源 PNG 字节锚点与具体示例。示例图不代表用户当前安装版本已与它一致。
3. **同一人物不同原画版本的逐动作对照**：左右面板展示该实际动作的总帧数、透明边缘归一化后的不同可见姿态数，并对“运动动作仅一帧”“多帧同姿态/平移立牌”“连续重复姿态”“完全透明帧”显示警告。A/B 共享互动下拉框也有 `⚠待核对`，可同步播放真实来源各自的动作序列，**不会补帧/跨版本借图/自动替换桌宠**。
4. **兼容已人工绑定身份的旧导入角色**：在对照入口用本地 `genshin_role_bindings.json` 的配置快照校验身份，不允许把 A 人物误配成 B 人物。

目前 123 是配置模板数，65 是已有固定可定位来源的人物数，不是 65 个已验收完备的内置美术。补全剩余 58 位角色需要合规、可信且具实际可播放动作的原图素材；找到网页版立绘、角色头像或表情贴纸并不等于可新增桌宠原画角色。

## 用户检查步骤

打开“角色库”→找到**已安装真实作者素材**对应人物→“原画 A/B 对照”。例如同一人物有 Shimeji 和另一套原画版时，选一段真实 `walk`、`crawl` 或 `fall` 动作，直接观察左右是否只有固定姿态平移、图像是否错位/裁断、外观头身比例/发饰是否与原设一致。逐帧确认后可在本机保存评价；不修改作者素材字节、原有角色配置和本地存档。

R7 记录的 14 套素材、28 项单帧移动风险仍需**实际修复或改用更好的同人物创作者动作**才能算缺口减少。R9 让它们更明显、也让用户可以安全比较替代版本，但不能将风险警告的数量减少理解为故障已解决。

## 非验收事项

CI 中的小图像是代码生成的测试像素，不是原神人物；CI 的 frame/pixel 差异无法判断作者画法是否“圆润Q版”，也无法证明原创配音、原设声音、角色服饰准确、动作自然、版权授权或 Windows 实体电脑上的持久桌面运行。
