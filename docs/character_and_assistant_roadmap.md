## PR 更新规则
每轮更新准确列出 commit SHA、实际新增不同人物数、资源版本数、测试通过/失败的具体 HEAD；缺来源者继续保留待补状态，绝不为了做满 123 制造人物图片。

## 本轮角色互动审计可信度整改（2026-10-26）

过去某个已导入创作者目录即使只有 `act_conf.json`、缺少真实 PNG，汇总也把它计入 `roles_with_creator_art`。现在改为**必须存在至少一个能够读取的原始 PNG 动作，才算该人物有创作者动画证据**；导入但无法播放的目录另计入 `creator_folders_with_broken_actions` 和 `roles_with_creator_folder_but_no_playable_actions`。同时记录每人 `playable_creator_role_count`，方便检查混杂的多版本素材。

这不替代人物长相、配色、声音、动画连贯性的人工 QA。逐角色来源覆盖（65/123）由独立素材 PR #25 的 SHA 来源登记提供；互动报告只统计用户机器上已安装且具备可读帧的目录，两种数字不可混用。新增混合好/坏 PNG、空目录和来源计数回归，继续保持 PR #26 独立于素材分支。

**素材最新验收边界：** 安柏、菲谢尔的 Git LFS 原始文件已有精确 SHA-256 与原生安装回执，但各自的 `crawl` 与 `fall` 动作只有一个不同姿态帧，仍须检查真实桌面坐标移动并由人工确认角色造型。因此 65/123 仅代表固定可验证的**来源**，不是 65 位真实动作或外观全部完成。
