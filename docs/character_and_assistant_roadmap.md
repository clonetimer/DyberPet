## P2：其他宠物功能并行收敛
- [ ] **动作交互**：待机、行走、悬浮、拖动、坠落、触碰、切换角色，允许缺失动作但不给假动画；高 DPI、多屏和托盘行为实测。
- [ ] **语音**：手动启动的 Vosk 录音、pyttsx3/TTS 音色试听、缺设备/缺模型提示、咕嘎/Doro 本地作者短音效与系统 TTS 隔离。
- [ ] **本地 LLM + PPL**：LM Studio 模型检查、本机 HTTP 限制、Persona DSL 快照按角色隔离；PPL Character Governance 单独服务，禁止把聊天内容隐式变为关系状态事件。
- [ ] **文件工具**：仅用户显式确认的目录和创建/删除到可恢复区/恢复，模型输出及语音文本不能直接获得删除权限。
- [ ] **非程序员体验**：首启引导、一键素材安装、角色筛选与真实帧预览、易懂的故障说明、设置备份/恢复。
- [ ] **可靠性**：长时间运行、音频和模型服务异常、掉线恢复、多宠内存与 CPU 预算。

## P3：发布门禁
- [ ] Windows EXE 与 Linux ELF 实际冻结包、PySide6 启动、实际显示设备、多 DPI/多屏、物理音频测试均有日志；GitHub Actions 不能替代原设视觉验收。
- [ ] Rust 实验分支只以相同的真实作者素材对照 Python 的解码像素、动作帧、内存与延迟；不提前替换默认 Python。
- [ ] 每个角色状态始终可信：不能把程序演示占位、模板、找到来源、安装成功误称原设形象通过。
