# R55 · Doro 单角色：个人本地一键启用

本轮**不再把个人使用与对外发布混为一谈**。用户只在自己的 Windows 电脑上使用 Doro；DyberPet 应做到下载后自动识别、解压、启用，避免逐张导入图片、配置角色或安装 Python 开发环境。

## 最少操作

1. 安装或解压 DyberPet R55 Windows 便携程序，进入“角色管理 → 咕嘎 / Doro → Doro 专项 Live2D”。
2. 如果电脑的 `下载/Downloads` 中已经有原作者的 Dororong ZIP，程序自动查找，私下解压到当前 Windows 用户的 AppLocalData/PersonalDoro，并加载模型。
3. 若无 ZIP，可在界面点击“打开原作者免费下载页”直接访问 https://booth.pm/zh-cn/items/5867617 取得。**这是原作者下载，不是要求从 Github 下载我们的复制品。** 下载一次，再进入 Doro 专项即可自动启用。
4. 软件也支持“选择已经下载的 ZIP（自动安装）”，用于浏览器把压缩包保存到自定义目录的情况。
5. 日后可在同一个 Live2D 界面点击“从下载文件夹自动启用原版 Doro（个人本地）”，无需手动解压 ZIP。用户也可选择已经解压过的模型。

## 源素材处理边界

- 不上传 GitHub，不发送给第三方，不内置到公开安装包，**但允许用户本机缓存他已经取得的源模型**。
- 用户的原始 ZIP 不会被更改；程序仅在用户自己可写的本机目录中解压模型必需文件，保持每张 PNG/Moc3 原始字节不变。按 ZIP SHA-256 的前缀建立私有文件夹，重复使用不重复复制。
- ZIP 内容经过防路径穿越、防 Windows 重名覆盖、防符号链接和体积限制检查；只取模型目录的必要数据文件并做 Cubism manifest 真实资源检查；不执行 ZIP 内脚本。
- 仍不将“Doro 在桌面可播放”宣称为“已经有独立正侧背三视图”或“作者提供完整四足动作”。这属于另一项艺术完成度验收，与用户个人本地使用权**分开处理**。
- 非人工美术验收不得将 Doro 标为完工；但**不会因三视图未完工而阻止本地播放**。

## 现阶段

R55 实现的是“个人 ZIP 自动发现/解压/启用、按需重新切换”，不自行登录 BOOTH 或绕过原作者页面。无需用户上传模型到 ChatGPT / GitHub，原作者模型也不交给任何 AI 图像工具作训练或生成。后续还需使用用户真实取得的 Dororong ZIP 在 Windows 电脑上测试视觉和实际互动。咕嘎及其他角色开发继续暂停。


## R56 · Doro 成为日常优先桌宠（个人本地、可恢复）

- 自动识别 Windows 的**实际“下载”位置**（含已重定向到 OneDrive 等路径），而非只查找 `%USERPROFILE%\\Downloads`；同时保留传统 Downloads 路径作为兼容回退。只扫描这两个已知位置，不搜索你的全部磁盘。
- 打开 Doro 预览后，可勾选 **“以后启动 DyberPet 时优先显示 Doro（原桌宠暂时隐藏；关闭 Doro 后恢复）”**。此选项**默认关闭**，不会私自替换你的原有角色。
- 用户明确启用后，下次启动程序自动尝试加载已经保存的本机模型；模型移动或损坏时再检查本机下载 ZIP 并静默安装。只有找到能通过 Cubism 文件检查的模型才启动 Doro，避免错误弹窗阻塞程序启动。
- Doro 独立桌宠出现时暂时隐藏旧桌宠；关闭 Doro 窗口则恢复原桌宠，不修改其原有角色数据、设置和进度。首次安装仍保留正常的新用户选角流程，不强行抢占弹窗。
- **不是 Windows 开机自启动**：这里只控制 DyberPet 本身启动以后显示哪个桌宠，不修改 Windows 自启动项、不安装服务、不联网。勾选取消即可恢复原有行为。
- 这些属于用户本人本机使用优化。Doro 的独立正侧背三视图和完整原生四足动作仍未达到最终验收标准。
