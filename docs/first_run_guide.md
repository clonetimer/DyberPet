# 首次使用：无需命令行，选角色即可开始

Windows 便携包解压后运行 `DyberPet.exe`，或在已支持的 Linux 桌面启动 `DyberPetDesktop`。**全新安装、没有旧 settings.json 的首次正常启动**会自动出现「欢迎使用桌宠」。

1. 输入角色名，列表仅展示本机已有原生动画的桌宠，不展示只有名字的角色模板。
2. 选择角色，查看真实 PNG 缩略图；可点击「预览角色动作」播放本机素材。
3. 点击「使用这个桌宠」立即切换并保存为下次默认角色。也可以选择「保留当前桌宠」。

之后想换角色，可以随时进入 **系统 → 角色管理 → 快速选桌宠**；高级筛选仍在「全部角色库」。

首次引导不会自动下载角色素材、要求登录、访问 LM Studio/PPL、启用麦克风或修改已导入的角色资源。生成的 Q 版演示明确标注「程序原创演示」，不代表游戏角色原设美术或语音。

## 边界与验收

- 已有 `data/settings.json` 的用户不被强制弹出欢迎页面，原存档不变。
- 主程序 Windows/Linux 冻结候选包通过真实 Qt/PNG 初始化检查；Linux 使用 Xvfb/XCB 检查弹窗可见和本机 Kitty 预览。
- 角色列表按已安装文件结构筛选；错误或不完整的角色可能需要先在角色管理重新安装。
- CI 不能替代真实 Windows DPI/多屏、点击交互、声音、长时间运行人工验收。
