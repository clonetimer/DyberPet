# DyberPet Q版角色扩展：实施与验收

## 本阶段交付

Q版角色不是一张静态头像：同一角色应包含透明背景逐帧动画、动作映射、统一脚底基线、互动气泡和信息卡。现有 DyberPet 布局保持不变，通过 **系统 → 角色管理 → 添加角色** 入口导入。

## 如何在 Windows 使用

1. 下载符合使用条件的角色 Q版动画素材，在本地整理为 Codex Pets V1/V2 图集文件夹，里面有 pet.json 与 spritesheet.webp 或 spritesheet.png。
2. 在运行 DyberPet 的 Python 环境执行 `py -m pip install "Pillow>=10,<13"`。
3. 打开 **系统 → 角色管理 → 添加角色**，选择该文件夹；出现一个紧凑的模板选择对话框。可以使用原图集的名称，只启用 Q版缩放，也可以选择原神/无限机兵/其他模板。模板不修改原图集作者，且不会下载官方美术素材。
4. 查看导入成功的角色、气泡、封面与动作；建议重启应用做完整桌面测试。

命令行批处理示例：

    py tools/import_codex_pet.py D:\art\paimon --style chibi --profile genshin_paimon --folder GenshinPaimon --author "实际素材绘制者" --license "实际素材许可" --source-url "作品链接"
    py tools/import_codex_pet.py D:\art\arrisa --style chibi --profile ailimit_arrisa --folder AILimitArrisa --author "实际素材绘制者" --source-url "作品链接"

**不要把某个角色名称当成素材来源的授权证明。** 作者/许可证/原始网址应对应具体图片创作者，不是原作公司名称或本项目开发者。

## 核心 Q版适配

- 基准尺寸：输入每格 192×208 px，保持所有原始透明帧的尺寸不变。
- 动态缩放：以待机可见高度的中位数与角色模板目标高度计算 scale（限幅 0.55–1.35），不会对每一帧重新拉伸。
- 站立、散步、休息、挥手等落地动作：以待机底部基线为参考，在每帧 ±16 px 的安全范围内做透明像素平移，且会防止裁剪。
- 若单帧需要更大调整，报告漂移并保留原始帧；跳跃、失败等非地面动作不强行贴地。
- 头像：Q版模式优先展示可见角色的上半部分；信息卡封面由图集本身生成。
- 互动：从预设生成单独的 note/bubble_conf.json；只使用新写的文字，不自动添加第三方配音。

## 局限及验收依据

`IMPORT_REPORT.json` 包含推荐缩放、动作帧数量、足底校正数量、几何统计及潜在漂移。它只能检查几何，不能自动判断是否为真正的Q版、人物是否和原角色一致、动作是否符合角色设定。

上线验收仍须在 Windows 用真实素材检查：脚部贴地、站立↔行走转换、跳跃是否被错误拉回地面、头像是否合理、对话气泡是否溢出、角色切换和现有角色是否正常。没有图集时，配置模板本身不能成为可显示的桌宠。
