# DyberPet 125 个角色：实际素材与验收状态

**版本范围**：2026-10-24 的 main 个人候选代码；PR #2、#5–#11、#13 已按序合并，PR #12 的角色归属修复已并入 #11。源码已集成，但未进行 Stable Release。

## 数量的含义

| 指标 | 当前设计 | 注意 |
|---|---|---|
| 角色模板 | 原神人物/伙伴 123 + 咕嘎、Doro 2 = **125** | 模板不是角色美术或动画 |
| 原创演示动画 | 候选安装包内共 **125 套**可播放的程序原创 PNG/动作配置 | 并非对应游戏/作者的原设作品；不代表形象或声音还原 |
| 用户导入素材 | 只统计本机用户确实安装并通过结构检查的角色 | 未导入时数值为 0 是正常的 |
| 原设完成度与实机 QA | 需逐角色核对形象、动作、配音和物理桌面行为 | 不能因为 CI 绿灯而自动通过 |

**“已关联角色数为 0”** 表示当前读取的角色目录尚无明确身份关联且安全预检通过的角色，**不表示 125 个模板消失**。从源码运行时并不自动生成演示 PNG；Windows/Linux 个人候选压缩包的构建脚本会预先生成内置演示。

## 原神、咕嘎和 Doro 有什么区别？

- **原神 123**：已复用通用动态预览、播放/暂停、角色切换与本机资源扫描；程序原创演示当前为每位 **10 类动作、66 帧**，主要是统一双足 Q 版形体，不是 123 位人物的专属外观、招式或原声。
- **咕嘎**：有企鹅风格原创演示皮肤（10 类/66 帧）；用户主动确认后可从固定上游作者图集本机获取和转换（已核验来源转换为 9 类/57 帧）。原图没有明确再分发许可，不放入公开程序包。
- **Doro**：有粉发四足原创演示皮肤（10 类/66 帧）；用户主动确认后可按固定上游二创图集获取转换（已核验 9 类/57 帧）。CC BY-NC 二创许可不等于底层游戏人物官方授权。

## 图形界面操作

进入 **系统 → 角色管理 → 全部角色库**，按中文名、英文名或模板 ID 搜索，并使用角色家族及素材状态筛选；选择人物后可查看来源、预览/暂停动作、切换当前桌宠或打开资源目录。原神素材关联等高级操作仍有单独入口；**「【进度】125 个角色的能力与素材覆盖情况」** 显示本机真实的演示素材数、个人导入数、可播放数和待补素材数。

在独立的 **「咕嘎 / Doro」** 页面，可查看各自原创演示和用户自行安装的作者图集。用户未主动确认时程序不会联网获取作者图片。

**角色族归属约束**：原神库只接受明确关联的原神角色；咕嘎/Doro 的来源收据不得通过额外身份绑定被错误认领为原神人物。矛盾、损坏或不安全的收据会在扫描中标记为异常；不会依靠目录名、发色或相似外观猜测归属。全部本机盘点流程只读，不向外上传个人数据。

## 自动化门禁和剩余工作

跨平台单测、Windows EXE 与 Ubuntu X11/Xvfb 冻结 ELF 可以检验动画能否加载、GUI 是否正常启动、归属关系是否一致。但它们**不能代替** GNOME/KDE/Wayland 物理显示器、多屏、音频设备、数小时稳定性和原设形象/音色对照的人工验收。

相关功能已逐层合并进 main（#12 先并入 #11，#13 搜索目录最后合入）。Windows/Linux 自动化测试已经运行，但尚未完成物理桌面、多屏、麦克风/声卡、长时间稳定性与原设还原度的人工验收；不应称为 Stable。实验性 Rust PR #3 与替代原神模板 PR #4 仍独立，不属于本轮主干收敛范围。
