# R5：真实作者Q版原画对照墙

## 目标
R4 已对个人包内的 65 套角色素材完成只读检查：15 套存在明显高瘦轮廓复核线索、14 套存在弱运动线索，其中有些重叠。**这些统计不等于已证明有15个立牌角色。** 为解决用户指出的“单薄的立牌感”，R5 将原画对照从导出 JSON 前置到桌宠界面。

## R5 桌面交互
1. 打开“角色库”→“查看真实Q版原画对照墙”。
2. 默认按风险强度显示真实作者素材首帧，保持原长宽比，不将 PNG 拉宽、压扁、人工Q化。
3. 每页最多18张，可按高瘦轮廓、弱运动、本人已标记不合格、本人Q版验收通过或全部素材进行过滤。
4. 点击“逐帧核对”进入**当前实际安装版本**的完整 PNG 查看器；本人可标记立牌/体态、原设差异、动作和桌面实测。返回时刷新本地记录。
5. 点击“作者素材来源”可以查看已经登记且固定来源的创作者候选链接；不会在没有本人同意时执行网络下载，更不会把未知来源说成更圆润的 Q版素材。
6. Q版审核始终使用 R4 逐版本、人工作画比对 + 完整动作帧检查门禁；任何未经审核版本均视为候选。

## 工程属性
- 不使用缩放拉宽来伪造圆润 Q版，不生成替代角色画面。
- 展示的缩略图均是本机安装原始作者 PNG，不上载到聊天或公开 GitHub。
- 一张卡对应一个实际已安装的 creator 版本，动作不跨版本合并。
- 只有作者来源与当前角色的固定身份映射才可浏览；链接限制为允许的 HTTPS 源。
- Windows 便携版打包显式包含动态加载的 Qt 对照墙、图片风险检查与人工记录模块。
- 保留 R4/R3 的 owner-only Draft 作为回退。
- 此轮提供视觉审阅和替换来源入口；**不会把未实际核验的15个形象宣称已经被替换**。

## 后续的真实替换验收
优先检查前15套风险角色的来源备选，先取得作者原始动画，核对许可和角色身份，再人工对比 Q版头身/服饰/动作。备用素材需要逐帧验证并由用户手动选用才进入本人Q版名单。Q版通过数量和已安装来源数量始终分开公布。
